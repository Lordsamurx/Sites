# Marquee

Faixa contínua com os nomes dos tratamentos em serifa itálica, separados por losangos dourados, que rola para a esquerda e esmaece nas bordas.

## Regras
- Entre o hero e a primeira seção, ou acima do rodapé.
- Duplique a lista uma vez no HTML: a animação percorre 50% e reinicia sem salto. 26,8s por volta.
- Pausa no hover; parada com movimento reduzido.
- Envolva com `aria-label` e marque a cópia com `aria-hidden="true"`.
- Também serve para logos de marcas parceiras (em tom único `text-muted`), só com direito de uso.
