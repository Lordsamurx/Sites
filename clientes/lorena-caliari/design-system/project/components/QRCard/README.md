# QRCard

Cartão branco com chamada em itálico e o QR code que abre o WhatsApp da clínica, para o desktop.

## Regras
- Título `display-badge` (26px, itálico): "Agende sua avaliação".
- QR de 163px, gerado para o link `wa.me` com mensagem pronta; `alt` com o destino.
- Só no desktop: abaixo de 900px troque por `lc-btn--block` "Falar no WhatsApp".
- Pode vir com uma anotação em `display-quote` ao lado.

## O que o consumidor fornece
A imagem do QR code (a prévia mostra um marcador).
