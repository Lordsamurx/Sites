# Overline

Rótulo curto em CAIXA ALTA espaçada (3px), com o brilho, que nomeia a seção acima de um título.

## Uso
`<p class="lc-overline"><svg>…brilho…</svg><span>Tratamentos</span></p>`, a `space-3` acima do título.
- Uma ou duas palavras: "Tratamentos", "Sobre a Lorena", "Resultados".
- Texto em `accent-text` (gold-ink); o brilho em `gold-dark`. Em painéis marrons, tudo em `accent`.
- `lc-overline--center` para seções centralizadas.
- Abaixo de 900px: 10px.

## Ornamento
`lc-ornament`: dois filetes de 1px com o brilho no meio, como na peça de Instagram. Use entre um título e o texto que o completa, no máximo um por seção.
