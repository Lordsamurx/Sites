# GlassPill

Pílula de vidro com borda em degradê dourado, para notas e avaliações sobre a foto do hero.

## Anatomia
`lc-glass` > `lc-rating` (estrela + `lc-rating__score` + `lc-rating__mark` + fonte), separados por `space-5`.
- `lc-glass` sobre fundo claro ou areia; `lc-glass--dark` sobre marrom ou foto escura.

## Regras
- Use só notas reais com fonte (Google, Doctoralia, Instagram). A prévia usa números de exemplo.
- No máximo três itens.
